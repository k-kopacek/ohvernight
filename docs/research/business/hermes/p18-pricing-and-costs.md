## Features that create disproportionate cost

- High-frequency availability alerts: each monitored campground/date combination requires polling, normalization, deduplication, retries, alert routing, and abuse controls. Campflare describes campground-level real-time availability, while Campnab and Schnerp price around scan frequency and scan slots. [Campflare API](https://campflare.com/api), [Campnab FAQ](https://campnab.com/faq), [Schnerp pricing](https://www.schnerp.com/pricing)
- Offline maps and satellite imagery: downloads multiply tile requests and storage, while satellite and raster tiles consume more credits or requests than basic vector tiles. [Mapbox pricing basis](https://docs.mapbox.com/accounts/guides/pricing/), [Stadia pricing](https://stadiamaps.com/pricing/)
- Parcel and landowner enrichment: parcel records, ownership, zoning, building footprints, tiles, update cadence, and commercial redistribution rights create both recurring data costs and licensing constraints. [Regrid plan options](https://support.regrid.com/reference/plan-options), [Regrid API](https://regrid.com/api)
- User-generated and official-source normalization: ingesting federal, state, local, and reservation-system data requires source monitoring, schema changes, attribution, freshness checks, and exception handling. [Campflare API](https://campflare.com/api), [Outdooractive API terms](https://corporate.outdooractive.com/en/api-terms/), [Recreation.gov data](https://www.recreation.gov/use-our-data)
- Map interaction at scale: panning, zooming, multiple layers, 3D terrain, search, routing, and uncacheable requests can drive usage-based map bills. [MapTiler pricing](https://www.maptiler.com/cloud/pricing/), [Esri basemap session pricing](https://www.esri.com/arcgis-blog/products/platform/announcements/basemap-sessions)
- Mobile-store subscriptions: Apple and Google fees reduce contribution margin on digital subscriptions, with different rules for small businesses, subscription age, region, and billing path. [Apple Small Business Program](https://developer.apple.com/app-store/small-business-program/), [Google Play service fees](https://support.google.com/googleplay/android-developer/answer/112622?hl=en)
- LLM enrichment and page monitoring: cost scales with page length, polling frequency, retries, context size, and output tokens; batch processing can reduce model cost but adds latency. [OpenAI API pricing](https://openai.com/api/pricing/)
- Email and alert delivery: high-volume alerts create costs for email, dedicated IPs, domains, SMS or WhatsApp vendors, push infrastructure, retries, and deliverability operations. [Resend pricing](https://resend.com/pricing), [Schnerp pricing](https://www.schnerp.com/pricing)
- Reservation transactions: bookings add payment processing, refunds, disputes, fraud controls, customer support, cancellation handling, and marketplace liability. [Hipcamp commission policy](https://support.hipcamp.com/hc/en-us/articles/360024823412-How-much-does-it-cost-to-list-on-Hipcamp-and-is-there-a-commission-fee), [Stripe pricing](https://stripe.com/pricing)

## Recommendation

For an initial Colorado pilot, use a low-fixed-cost architecture:

1. Static frontend on GitHub Pages or Cloudflare Pages.
2. Self-hosted PMTiles on R2, with aggressive caching and no satellite layer by default.
3. NWS forecasts and alerts for weather, with explicit rate-limit-aware caching.
4. Recreation.gov data where appropriate, preserving source links and treating availability as separate from permission.
5. Avoid parcel-data licensing until a narrow user need is demonstrated; if needed, start with county-scoped Regrid purchases rather than nationwide licensing.
6. Monetize first through an annual Plus-style subscription with a short trial, reserving high-cost features such as offline maps, alerts, satellite imagery, and advanced enrichment for paid tiers.
7. Treat booking as a later-stage integration because payment, cancellation, fraud, support, and marketplace liability are materially more expensive than discovery.
8. Instrument conversion, trial activation, paid renewal, alert usage, map sessions, tile volume, email volume, and source-refresh failures before choosing monthly versus annual pricing.
